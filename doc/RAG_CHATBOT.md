# RAG & Conversational Chatbot Architecture

The RAG (Retrieval-Augmented Generation) subsystem in `service/rag/` and `service/chatbot/` provides conversational QA grounded in curated news articles.

---

## Architecture Overview

The RAG chatbot decouples vector generation, document retrieval, and LLM completions into three distinct layers:

```
[User Query] ──> ChatbotService (service/chatbot/service.py)
                       │
         ┌─────────────┴─────────────┐
         ▼                           ▼
 EmbeddingProvider            DocumentStore
(Remote / OpenAI / ST)    (BM25 / Memory / Julep)
         │                           │
         ▼                           ▼
[http://embedding-server:8001]  [Vector / BM25 Search]
                                     │
                                     ▼
                            AgentProvider (OpenAI / Julep)
                                     │
                                     ▼
                            [Conversational Answer]
```

---

## Unified Embedding Service Integration

Text vector embeddings are generated by calling the standalone **`embedding_server`** microservice via HTTP REST:

### Provider: `RemoteEmbeddingProvider` (`service/rag/providers/remote_embedding.py`)
- **Config**: Reads `EMBEDDING_SERVICE_URL` (default: `http://embedding-server:8001`).
- **Endpoints**:
  - `POST /embed` — Single text query vectorization.
  - `POST /embed_many` — Batch article vectorization.
- **Model**: `sentence-transformers/all-MiniLM-L6-v2` (384 dimensions, normalized).

### Pipeline Synchronization
Both the ingestion pipeline (`pipeline/embeddings/providers/remote.py`) and the RAG chatbot query engine use this identical REST service, ensuring query vector representations match document embeddings exactly.

## Document Stores (`service/rag/`)

Configured via `RAG_BACKEND` env var:

| Provider | Implementation | Search Method | Description |
|:---|:---|:---|:---|
| `memory` | `MemoryDocumentStore` | Cosine Vector Similarity | In-process vector store using embeddings generated via `RemoteEmbeddingProvider`. |
| `bm25` | `BM25DocumentStore` | Okapi BM25 Lexical | Fast, dependency-free text ranking engine. |
| `julep` | `JulepDocumentStore` | Managed Remote Vector DB | Cloud-managed retrieval store hosted on Julep AI. |
| `none` | `DocumentStore` | No-op (`[]`) | Fallback disabled store. |

## Conversational Wiring & Service Usage

```python
from service.chatbot.service import ChatbotService
from service.rag.factory import create_doc_store
from service.agents.factory import create_agent

# Initialize RAG chatbot service
chatbot = ChatbotService(
    agent=create_agent(),             # Selected by AGENT_PROVIDER (openai / julep)
    document_store=create_doc_store() # Selected by RAG_BACKEND (memory / bm25 / julep)
)

# Perform conversational QA
response = chatbot.get_response(
    query="What is the latest update on EV manufacturing in India?",
    user_id="user_123"
)
```
